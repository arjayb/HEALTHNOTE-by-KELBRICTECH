# Security and Responsible Disclosure

HEALTHNOTE is intended to handle highly sensitive personal information. Security and privacy issues must be treated as product-critical.

## Prototype rules

- Do not submit real patient records through public issues.
- Do not include identifiable medical information in screenshots, logs, test fixtures, or pull requests.
- Use synthetic data for demonstrations and tests.
- Do not publicly disclose a vulnerability that could expose user information.

## Reporting

Until a dedicated private security channel is published, report potential vulnerabilities privately to KELBRICTECH through its official contact channel. Include only the minimum information necessary to reproduce the issue and never attach real patient data.

## Scope statement

The repository currently documents an early prototype. No claim of regulatory certification, medical-device approval, or suitability for clinical decision-making is made.
